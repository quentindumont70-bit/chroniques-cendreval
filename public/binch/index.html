La Binch · synchronisation

Ton personnage, tes données

Il existe deux façons d'utiliser La Binch. Pour commencer, la saisie manuelle suffit. L'import depuis WoW est optionnel et reste expérimental.

Option A — sans installation

La plus simple

Personne n'a besoin d'installer un addon pour consulter les quêtes, recettes et outils de guilde.

  1. Ouvre Quartier général.
  2. Renseigne ton nom et ton niveau dans Ton identité de jeu.
  3. Les suggestions resteront indicatives jusqu'à un import depuis le jeu.
Option B — importer depuis WoW

Avec GrimoireSync

Installation manuelle de deux petits fichiers. Aucune clé API ni compte supplémentaire.

  1. Ferme WoW avant de copier les fichiers.
  2. Crée GrimoireSync dans le dossier Interface/AddOns de ton installation WoW Forever.
  3. Télécharge GrimoireSync.toc et Core.lua et place-les dans ce dossier.
  4. Relance le jeu, active l'addon à l'écran de connexion, puis connecte ton personnage et tape /reload.
  5. Sur La Binch, utilise le bouton Choisir GrimoireSync.lua ci-dessous et ouvre WTF/Account/[compte]/SavedVariables/GrimoireSync.lua.

Le navigateur ne lit pas WoW automatiquement. Il faut refaire l'import après de nouvelles sessions. L'addon n'a pas encore été validé sur tous les clients Forever.

Si tu ne trouves pas le fichier, fais d'abord /reload dans le jeu. Tu peux utiliser La Binch sans aucune synchronisation pendant la bêta.
