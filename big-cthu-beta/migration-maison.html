🏡 Pont de migration Maison

Importer uniquement les fiches d'équipement depuis un export JSON de l'ancienne tentacule Maison de Claude, sans connexion au compte Claude et sans upload.

Compatibilité ciblée avec la structure historique eq (nom, marque, modèle, garantie, notes). Les autres rubriques restent dans le fichier Claude original : entretiens périodiques, historique, documents, budgets, contrats, etc.

1. Sélectionner un export Maison

Les fichiers sont lus localement par le navigateur. Si le document contient des données personnelles confidentielles, ne l'utilise pas sur un appareil partagé.

Aucun fichier sélectionné.
Ce pont ne permet pas encore la migration complète de Maison. Les données Claude ne sont jamais effacées. Les anciennes versions doivent rester accessibles jusqu'à la vérification fonctionnelle de tous les modules.
