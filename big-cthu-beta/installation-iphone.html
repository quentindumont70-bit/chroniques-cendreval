📱 Big Cthu sur iPhone

Un raccourci qui ouvre tes outils directement depuis l'écran d'accueil, sans ChatGPT, Claude, Work, Codex ou compte d'IA. Le site statique est hébergé par GitHub Pages ; la météo de Voyages reste facultative et utilise un fournisseur externe uniquement à ta demande.

Configuration recommandée : une seule icône Big Cthu. Tu ouvres ensuite Budget, Voyages, Cantine, Maison et les autres tentacules depuis le cockpit. Cela évite de multiplier les applications web avec des stockages locaux potentiellement distincts.

Installer l'icône principale

  1. Sur l'iPhone, ouvre Safari et le lien du cockpit ci-dessous (pas le navigateur intégré d'une autre app).
  2. Appuie sur Partager puis sur Sur l'écran d'accueil.
  3. Active « Ouvrir comme app web » si cette option apparaît, puis touche Ajouter.
  4. Ouvre l'icône « Big Cthu ». Toutes les tentacules sont accessibles depuis le cockpit.

Avant de supprimer les anciens raccourcis

Attention aux données : Safari, une app ajoutée à l'écran d'accueil et une app créée depuis un autre raccourci peuvent utiliser des stockages séparés, même lorsque le site paraît identique. Créer une icône n'importe pas automatiquement les données de l'ancienne.
  1. Ouvre chaque ancienne app contenant des informations à conserver et cherche sa fonction d'export ou de sauvegarde.
  2. Conserve les fichiers exportés dans un emplacement privé, par exemple l'app Fichiers, sans données sensibles.
  3. Ouvre le nouveau Big Cthu, puis le Coffre de sauvegardes. Importe uniquement les formats explicitement compatibles. Les sauvegardes provenant d'une autre app ne sont pas migrées automatiquement.
  4. Vérifie que tes éléments sont bien visibles et modifiables dans l'app installée. Garde les anciens raccourcis tant que ce contrôle n'est pas terminé.

Les données Big Cthu sont locales : pas de sauvegarde dans un cloud Big Cthu, pas de synchronisation automatique entre appareils. Ne stocke pas de données de patients ni d'informations sensibles dans cette bêta.

Vérification sur cet appareil

Mode d'ouverture à déterminer.

Ce bouton teste uniquement l'enregistrement local d'une valeur fictive, puis l'efface. Il ne lit aucune de tes données personnelles.

Tournée officielle : une seule version chiffrée

Ouvrir Tournée complète chiffrée. C'est l'unique version mise en avant dans Big Cthu. Tournée s’ouvre directement, sans écran de verrouillage ni phrase secrète à saisir, même lors d’une première visite. Le bouton « Récupérer mes anciennes données » reste accessible même sur un nouvel appareil : un ancien export JSON classique se récupère sans code. Seul le déchiffrement volontaire d’un ancien coffre chiffré exige sa phrase historique. La protection par code du téléphone reste celle que tu utilises. L’enregistrement local conserve un chiffrement automatique sans te demander de code. Si tu avais déjà un ancien coffre protégé, ses données restent intactes : utilise seulement l’option « Récupérer mes anciennes données » depuis l’application pour les retrouver. Une ancienne phrase secrète peut être indispensable uniquement pour déchiffrer ces anciennes données, pas pour ouvrir Tournée. Protège l’accès à ton téléphone.

Pour terminer une migration : ouvrir uniquement l'ancienne Tournée pour exporter une sauvegarde. Vérifie le fichier exporté dans un emplacement privé, restaure-le dans la nouvelle application si son format est compatible, puis contrôle toutes les rubriques avant de retirer l'ancien raccourci. Ne supprime jamais l'ancien stockage ou le fichier source pendant ces vérifications.

Transférer le coffre complet et le journal d’absences : sur l’ancien appareil, ouvre Tournée complète directement et touche « Exporter une sauvegarde complète JSON ». Ce fichier est lisible sans code et contient toutes les rubriques du coffre : conserve-le dans un emplacement privé et ne le dépose jamais en ligne. Sur le nouvel appareil, ouvre Tournée directement puis utilise « Récupérer mes anciennes données » pour restaurer le JSON sans phrase secrète. Le bouton « Copie chiffrée locale » ne produit pas un fichier transférable sans la clé cryptographique de cet appareil. Contrôle la liste, les modifications et leur historique avant de supprimer un ancien raccourci. Le JSON classique de Tournée n’inclut pas ce journal.

Important : ne dépose jamais une sauvegarde de patients dans le Coffre général et ne publie aucun fichier clinique dans GitHub ou dans le chat. Garde ton ancien accès jusqu'à vérification indépendante de toutes tes données.

Essai de reprise iPhone sur données fictives

Protocole de vérification uniquement : ne commence pas avec tes dossiers réels. Conserve une sauvegarde indépendante et utilise un navigateur de test sans données cliniques.

  1. Dans un environnement de test vierge, ouvre Tournée sans créer de phrase secrète, puis utilise exclusivement des patients inventés.
  2. Ouvre Tournée complète directement et crée un signalement fictif dans Absences & modifications.
  3. Passe Safari en arrière-plan, puis reviens. Après 15 minutes sans activité, confirme que Tournée reste ouverte sans te redemander de phrase secrète, et que les modifications fictives restent présentes. Ferme puis rouvre l’onglet pour valider l’ouverture automatique.
  4. Utilise « Exporter une sauvegarde complète JSON » depuis le navigateur de test (données fictives), puis restaure ce fichier dans un second navigateur vierge sans code.
  5. Contrôle les événements fictifs, les annulations, les filtres et l'historique. Essaie aussi une mauvaise phrase secrète sur l'environnement de test.

Ne supprime aucun stockage, raccourci ou fichier de sauvegarde durant les essais. Une fermeture forcée d'iOS ne garantit pas la fin d'une sauvegarde en cours ; cette checklist n'est pas une validation pour usage clinique.

Réseau, mises à jour et autonomie

État du réseau à déterminer.

Essai hors ligne sans données réelles : ouvre d'abord Tournée complète en ligne une fois afin que son cache public puisse s'installer, puis passe en mode avion et réouvre l'application sur des exemples inventés. Le bandeau « Hors ligne · stockage local » indique uniquement l'état réseau : vérifie aussi que Tournée s'affiche et que le test de sauvegarde réussit. Ne vide jamais le stockage Safari pour cet essai.

Après une première ouverture en ligne et la mise en cache, les pages publiques déjà téléchargées peuvent rester accessibles sans réseau. Les prévisions météo ne sont pas disponibles hors ligne, et les données saisies ne quittent pas cet appareil, sauf téléchargement de sauvegarde ou appel externe demandé.

Les nouvelles versions arrivent depuis GitHub Pages, sans intervention d'une IA. Lorsque le cockpit détecte une mise à jour, il propose un rafraîchissement. L'iPhone reste susceptible de supprimer des données locales sous certaines conditions : exporte régulièrement le Coffre.

Cette bêta n'est pas encore un produit destiné au traitement de données professionnelles ou médicales. La Tournée Big Cthu dispose de pages séparées, dont une version chiffrée ; elles ne constituent pas un hébergement HDS certifié. Ne confonds jamais une sauvegarde Tournée avec le Coffre général. Topaze n'est pas remplacé.
